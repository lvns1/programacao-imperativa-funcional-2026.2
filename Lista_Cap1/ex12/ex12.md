| Instrução | Status (C/I) | Justificativa Teórica |
| :--- | :--- | :--- |
| `int a;` | **Correto** | Declaração válida de uma variável inteira simples. |
| `float b;` | **Correto** | Declaração válida de uma variável de ponto flutuante de precisão simples. |
| `double float c;` | **Incorreto** | Sintaxe inválida. Não é permitido combinar os especificadores de tipo `double` e `float` na mesma declaração. |
| `unsigned char d;` | **Correto** | Declaração válida de um caractere sem sinal (armazena valores numéricos inteiros de 0 a 255). |
| `unsigned e;` | **Correto** | Declaração válida. O tipo base `int` é assumido implicitamente pelo compilador C quando se usa apenas `unsigned`. |
| `long float f;` | **Incorreto** | Sintaxe inválida no padrão ANSI C. Para variáveis de ponto flutuante com precisão expandida, deve-se utilizar `double` ou `long double`. |
| `long g;` | **Correto** | Declaração válida. O tipo base `int` é assumido implicitamente pelo compilador C quando se usa apenas `long`. |
| `long double h;` | **Correto** | Declaração válida de um tipo de ponto flutuante com máxima precisão computacional. |
